# Parcours utilisateur principal (Touriste)

1. Arrivée (Home) — comprendre l'offre, être rassuré
2. Exploration — se projeter par destination/envie
3. Recherche — trouver une offre précise (dates, lieu, budget)
4. Consultation fiche — vérifier détails, prix, avis, disponibilité
5. Décision — comparer plusieurs options
6. Booking — renseigner les infos voyageurs
7. Paiement — payer en confiance (Wave, Orange Money, carte)
8. Confirmation — être rassuré, connaître les prochaines étapes
9. Suivi — suivre la réservation via dashboard
10. Post-séjour — laisser un avis, inciter au retour

Règle clé : recherche/consultation libres sans compte.
Compte requis uniquement à l'étape Booking (réduction de friction).
