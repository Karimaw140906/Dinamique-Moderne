33. MCT — MODÈLE CONCEPTUEL DES TRAITEMENTS
--------------------------------------------------

Construire le MCT.

Identifier les événements déclencheurs, traitements et résultats.

Exemples :

Le client ajoute une destination.

↓

TRAITEMENT :
Ajouter la destination à l'itinéraire.

↓

TRAITEMENT :
Recalculer la durée.

↓

TRAITEMENT :
Recalculer le budget.

↓

RÉSULTAT :
Nouvel itinéraire affiché.

Autre exemple :

ÉVÉNEMENT :
Le client retire une destination.

↓

TRAITEMENT :
Supprimer l'étape.

↓

TRAITEMENT :

↓

Nouvel itinéraire + nouveau budget.

Autre exemple :

↓

TRAITEMENT :
Valider les données.

↓

TRAITEMENT :
Créer une demande.

↓

RÉSULTAT :
Demande enregistrée.

Le MCT doit couvrir tous les traitements principaux du simulateur.

36. MOT — MODÈLE ORGANISATIONNEL DES TRAITEMENTS
--------------------------------------------------

Construire le MOT.

Identifier :

- qui réalise chaque traitement ;
- quand ;
- où ;
- avec quel outil ;
- selon quelle fréquence.

Exemples :

CLIENT
→ construit son voyage
→ interface web
→ en temps réel

ADMIN
→ gère les destinations
→ dashboard admin
→ selon les besoins

SYSTÈME
→ calcule le budget
→ automatiquement
→ à chaque modification

SYSTÈME
→ sauvegarde temporairement le voyage
→ automatiquement
→ pendant la session

ADMIN
→ traite une demande de réservation
→ dashboard
→ après demande client.

Le MOT doit permettre de comprendre l'organisation réelle du système.

↓
MPD

MCT

↓
MPT

Aucune incohérence ne doit exister entre les modèles.

Exemple :

Si une donnée apparaît dans le MCD mais n'existe pas dans le MPD,

Si un traitement existe dans le MCT mais n'est pas prévu dans le MPT,
identifier le problème.

Si une communication apparaît dans le MCC mais n'est pas prévue dans le MPC,
identifier le problème.
