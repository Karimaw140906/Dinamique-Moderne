# Structure de la Home

1. Header sticky — navigation + accès recherche rapide
2. Hero + barre de recherche — conversion immédiate
3. Réassurance rapide — paiement sécurisé, support local, annulation flexible
4. Destinations phares — cartes cliquables (Dakar, Saly, Casamance, Saint-Louis...)
5. Offres/hôtels populaires — carrousel avec note, prix, badge
6. Activités/expériences incontournables — upsell immersif
7. Pourquoi Sama Senegal — positionnement/différenciation
8. Témoignages / Avis clients — preuve sociale
9. Contenu éditorial (blog/guides) — SEO + immersion
10. Newsletter / App mobile — rétention
11. Footer — navigation secondaire + légal

Logique : recherche immédiate → inspiration → réassurance → preuve sociale → rétention.
